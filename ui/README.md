# Aria UI (Optional)

This frontend is an optional manual test harness for the Aegra backend.

## Run

```bash
npm ci
npm run dev
```

## Environment

Copy `.env.example` to `.env` and adjust values if needed.

- `VITE_AEGRA_URL`: Aegra backend URL (default `http://localhost:4242`)
- `VITE_AEGRA_ASSISTANT_ID`: default assistant/graph id (default `aria`)
